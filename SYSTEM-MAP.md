## Runtime flows

### Browser download

`platform adapter → overlay-core → background.js (Douyin may resolve media inside the active page without exporting cookies) → POST /enqueue → DownloadManager → allowlist validation → DownloadEngine → yt-dlp → MediaConverter when required → history/notification`

### Pasted link

`ContentView focused paste field → automatic submit with configured defaults → DownloadManager.enqueue → URLNormalizer → FIFO scheduler → DownloadEngine`

### Offline media tool

`menu-bar footer → independent SwiftUI window → module validates selection → MediaToolCommandBuilder → MediaToolRunner → FFmpeg/FFprobe → progress + output reveal`

### Finder Quick Action

`Finder selected file → macOS Service → FinderQuickActionCenter → owning module window → existing MediaToolCore/MediaToolRunner`

### Settings synchronization

`App settings → UserDefaults → GET /preferences → background minute alarm → changed keys only → storage.sync → content-script listener`

`Extension popup edit → storage.sync → POST /preferences → DownloadManager published preferences`
